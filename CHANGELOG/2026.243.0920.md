# 2026.243.0920 — docs: correct a changelog entry that named the wrong ref

## Summary

Corrects this repo's `CHANGELOG/2026.243.0915.md` entry, which described a
`layer-sway-desktop` usage example that **this repo never changed**.

The PR body IS the changelog here: it is written verbatim into `CHANGELOG/` at merge.
The prose sweep that produced that release reused a SINGLE body across 23 repos whose
diffs each touch different refs, so this repo's entry named a ref belonging to a
different repository.

The refs that release actually changed, read from its merge commit `04d8ddffdc7a`:

```
  @github.com/opencharly/layer-agent-forwarding:v2026.243.0408
  @github.com/opencharly/pod-dbus:v2026.235.2115
```

Each became `:vTAG`.
